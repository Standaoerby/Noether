## Задача — `Code/sim_polariz.py`
Новый модуль. По ФИНАЛЬНОМУ состоянию + event-логу прогонов (бери `run` из `sim_comm` и
`run_policy(MockStrategicPolicy())` из `sim_comm_llm`) считает ДЕТЕРМИНИРОВАННЫЕ метрики и
печатает их по режимам `none / honest / deceptive / mock-strategic`. Субъективные памяти агентов
уже расходятся (особенно при обмане) — это и есть субстрат для фракций; новой динамики не вводить,
только измерять существующую.

Метрики (выбор точного estimator'а — за тобой; жёстко лишь детерминизм и смысл):
1. **Поляризация веры.** Для каждой клетки, о которой ≥2 живых агента имеют мнение (в их `mem`),
   стандартное отклонение их believed-food. Агрегат = среднее по таким клеткам, взвешенное числом
   «верующих». Ожидание (ПРОВЕРЬ, не подгоняй): обман повышает поляризацию.
2. **Фракции.** Построй по агентам вектор отклонений их вер на наборе «спорных» клеток (высокая
   межагентная дисперсия). Кластеризуй **детерминированно, без RNG**: порог-граф «согласны в пределах
   ε» + связные компоненты (или агломеративно с фиксированным правилом). Печатай число фракций и их
   размеры по режимам.
3. **Распространение.** Для выборки `communication`-событий: сколько агентов изменили веру о
   заявленной клетке в пределах N think-дней (охват claim'а). Чисто из лога.
4. **Rationale-vs-outcome (агрегат).** По mock-strategic: доля само-интересных/обманных claim'ов и
   реализованный разрыв «элита − аудитория» (средняя туша). Один пример уже печатает `sim_comm_llm`;
   здесь — агрегат по прогону.

Требования: всё ДЕТЕРМИНИРОВАННО (две прогонки байт-в-байт; добавь само-ассерт на это),
pure stdlib + numpy, число API-вызовов = 0. Числа в докуи/PR — **ИЗМЕРЕННЫЕ, не ожидаемые**
(правило дома). Впиши `sim_polariz` 13-м в `Code/verify_all.py`:
```python

```
Гейт обязан остаться зелёным (**13/13**, deterministic=yes).
