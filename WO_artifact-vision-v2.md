Инъекция v1 инертна по трём причинам; две — свойства мира, одна — дизайна:

## 2. Дизайн v2 — два флага, оба OFF ⇒ бит-в-бит виток 2

### 2.1 `store_settle: bool = False` — зерно ссыпают день
`stage3/artifact.py`, проход `_store_draw`: при settle ON пить можно только из
складов `art.born_t < t` (свежая чеканка недоступна до следующего тика). Не новая
сила — физическая пауза; массу не создаёт и не уничтожает, лишь задерживает перенос
на тик. OFF ⇒ путь исполнения байт-в-байт прежний (гейт MFv3-OFF). Настоящее время
стояния при ON — эмпирика (HV0), не обещание.

### 2.2 `store_vision: bool = False` — зрение внутри канонического восприятия
Вместо пост-хок записи в конце step — **override `_observe` в Polis** (метод живёт в
`CommWorld`, MRO `Polis ← Appropriation ← Enclosure ← Salience ← Sphere ← CommWorld`
— проверено; сабклассинг = задокументированный шов канона, тем же паттерном mod B
подменял спикера). Контракт:

```python
def _observe(self, a):
    super()._observe(a)                      # каноническая правда (plant, t)
    if not self.cfg.store_vision: return     # OFF ⇒ ровно super(), ни байта сверх
    drawable = Σ mass живых store на клетке пешки, проходящих access-фильтр ЕЁ глазами
    if drawable > 0:
        переписать память ЭТОЙ клетки значением (plant + drawable) В ТОЧНОМ формате
        канонической записи _observe (переиспользовать stage3/vision.py v1 — формат
        там уже 1:1, меняется только точка вызова; discard-семантику hearsay не ломать)
```
Порядок становится правильным автоматически: наше observe (правда+зрение) → decide →
move. Никаких новых каналов, радиусов, вербов. Только store, только своя клетка,
access в глазах — всё как v1.

## 4. Пре-рег эксперименты (честные базы: интеграл, исторический класс, base rates)
- **HV0 — время жизни запаса.** settle ON: распределение standing-тиков складов,
  box6 vs arena none, до первого draw и до руины. Сама величина — новая ось мира.
- **HV1 — факторизация находки 6.** Три мира × две арены × сиды 7/8/9, 300 тиков:
  A={settle OFF, vision OFF} (виток 2), B={settle ON, vision OFF} (запас живёт, но
  невидим), C={settle ON, vision ON} (живёт и виден). Метрики HG1 (deaths, med.life,
  draws, Σdrawn, own%). B−A = вклад самого стояния; C−B = вклад информации. Исходы
  пре-рег: инверсия / железный NULL / частичный сдвиг — все три результат.
- **HV2 — молва.** Только в мире C: доля канонических claim'ов, чья целевая клетка
  несёт стоящий склад, против базовой доли в мире A (случайные совпадения). Рост =
  карта запасов пошла по социальной сети БЕЗ единой правки каналов.
- Контекст-метрика (печатать, не чинить): доля пешек, доживших хотя бы до одного
  think-тика (THINK_EVERY=6 при med.life 4–5 — когниция может быть привилегией
  долгоживущих; это интерпретационная рамка всех HV).
