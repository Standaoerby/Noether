## 1.3 Оверлеи — проектные решения (предложение Гайки, утвердить Стану)

**Протокол (аддитивно, v1):** клиент шлёт `layers{enable:[names]}` (повторное
сообщение полностью заменяет подписку); сервер кладёт в каждый снапшот поле
`layers: {name: [[rows×cols]]}` ТОЛЬКО для включённых. 196 клеток × few слоёв —
копейки. Правку протокола — сперва в `docs/game-architecture.md`, тем же PR.

**Слои и источники (имена канонизируем здесь):**

| name | источник | семантика клетки |
|---|---|---|
| `thermal` | `w.T` | температура K |
| `food` | `w.plant` | еда |
| `soil` | `w.soil` | плодородие |
| `ownership` | `w._cell_owner` | oid владельца / −1 |
| `density` | агрегат по агентам | счётчик пешек |
| `wealth` | Σ(body+store) по клетке | кг+запас |
| `debt` | агрегат `w._debt` | счётчик должников (stage>0), отдельно bonded |
| `reputation` | speaker/owner/марки | счётчики per cell |

**Клиент:** тумблеры-хоткеи (напр. F4–F8 или буквы — на вкус исполнителя,
задокументировать в HUD), полупрозрачная заливка поверх тайлов, легенда со
шкалой; нормировка min/max текущего кадра с подписью диапазона (косметика —
client-side). Пустой модуль → честная плашка «нет данных».

## 1.4 Хроники — уточнение

Сервер помечает высокосигнальные события аддитивным флагом `hi:true` в потоке
`events` (white-list видов из WO: birth/death/communication/extort/
delegate_remit/debt_*/pg_punish). Клиент строит ленту только из hi.
`cognition/move/forget` — никогда. Нарратив: `EventLog.narrate` где есть,
иначе `t · kind · actor · где`. Клик по строке → фокус камеры + инспектор
актора. Гейт CHRONICLE-FILTER из WO. База label/text — из 1.2.3.
