влитого faithful-ledger (`WO_faithful-ledger.md`, PR — Ф0–Ф2). Исполнитель: Claude Code. Отдельной веткой.

## 0. Что разблокировано (факт из faithful-ledger)

FL-MARK-FAITHFUL/FL-MASS зелёные — реплей событий == состояние. Плюс уже были `extort`/`delegate_remit` (dm).

⇒ E1-Ф0-развилка «3 карточки на снимках» снята: все шесть проекций теперь имеют событийную опору.

## 2. Работа по карточкам

| карточка | было (виток 1) | становится (виток 2) |
|---|---|---|
| **PropertyHistory** | снимко-производная (`owners` по тикам) | **лог-производная** (`claim`/`lose`/`inherit`); E1-FAITHFUL распространяется — реплей == `_cell_owner` |
| **ReputationHistory** | отсутствовала (deferred) | **новая, лог-производная** (`mark`/`unmark`): когда заклеймён/снят, кем (extort/delegate) |
| **PowerFlowHistory** | отсутствовала (deferred) | **новая, лог-производная**: `appropriate` (payers/receivers per-cell) + `extort` + `delegate_remit` — леджер потоков массы-власти per oid, знак из ролей |
| Chronicle · House · Relationship | лог-производные | без изменений |

**Нарратив (Ф2 виток-1) дополняется** новыми осями: карточка героя теперь несёт и «сколько отнял/у кого»
(PowerFlow), и «был ли клеймён» (Reputation) — по тому же гейту честности (факты-как-дуга, без мотива).
