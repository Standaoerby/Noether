# WO — mod H3: ЭНФОРСЕР. Принуждение как последний вопрос линии H (долг + общественное благо)

Дата: 2026-07-13. Составлен Гайкой после приёмки H2-bis (PR #60).
Решения Стана 13.07: public goods слит в H3 (один орган, два применения);
идёт ДО геймдева; множитель — эмпирически (фаза 0 + ось свипа).
Исполнитель: Claude Code, Windows 11, PowerShell. Ветка `feat/stage3-mod-h3`
от `origin/main`.

> **Зачем.** Линия H закрыта финальным NULL: согласие (долг) не строит власть —
> с честным дефолтом, наследуемым правом и открытым каналом кредита страта не
> возникает, тело правит. Принуждение — последнее неиспытанное звено. Полевые
> данные (письмо: public goods у детей/подростков) показывают: один и тот же
> санкционный институт даёт кооперацию ИЛИ элитный картель — решает контроль над
> наведением. Строим орган принуждения и задаём башне оба вопроса: HP3 —
> пробивает ли захваченная санкция потолок тела; HD1 — становится ли долг
> властью, когда требование можно исполнить силой. Нить:
> волт `Нить — общественное благо и захват наказания.md`.

## Фаза 0 — эмпирическая калибровка множителя (лёгкая, без стоп-точки)

- [ ] **0.1** Измерить из существующего мира (микропрогон, дефолтные ручки):
      одиночную урожайность пешки (масса body-прироста за тик с клетки) и
      фактическую ёмкость/восстановление soil клетки. Напечатать числа с
      выводом: какой суммарный поток физически доступен полю из n участников.
- [ ] **0.2** Выбрать точки свипа множителя m по критическому отношению m/n
      (классика: кооперация индивидуально невыгодна при m/n < 1):
      m = 1.0 (контроль, синергии нет) · m около n·1.0 (порог) · m выше порога.
      Точки ОБОСНОВАТЬ числами из 0.1 — синергия не имеет права обещать массу,
      которой нет в soil. Если ёмкость режет верхнюю точку — честно записать
      (перекос от лабораторной игры с безграничным множителем — сам по себе
      результат).

## Фаза 1 — орган принуждения + общественное благо

Механика (минимальная, поверх существующих каналов):
- [ ] **1.1** `pg_on` (дефолт False = байт-идентично): общее поле демы.
      Вклад body→pool — решение пешки на тик; pool открывает soil-поток с
      эффективностью m (проводка из soil, гейт консервативности); распределение
      поровну живым участникам демы (включая нулевых вкладчиков — как в игре).
- [ ] **1.2** `contrib_visibility` ∈ {anon, signed} — два круга письма.
      При signed вклады видимы через существующий канал наблюдения.
- [ ] **1.3** `punish_on` (дефолт False): после раунда — голосование
      большинством (существующий интент/deme-канал), жертва теряет 20% body
      → в soil. Правило наведения — стратегия пешки, ручка
      `punish_strategy` ∈ {min_contrib (норма), max_body (захват),
      coalition (свой-чужой по deme/интент-группе)}.
- [ ] **1.4** Печать: вклады по раундам, штрафы (кто→кого→за что по стратегии),
      Gini/topGap, средний против максимального итог — колонки письма.

Пре-регистрация Фазы 1 (обе формулировки, в докстринг ДО прогона):
- **HP1 (калибровка об реальность, D5):** anon + punish_off → вклады затухают
  к ~0. (а) воспроизвели мировую классику — башня откалибрована об известный
  человеческий паттерн · (б) не затухают → чем субстрат отличается от
  лаборатории (смертность? метаболизм? deme-структура?) — находка.
- **HP2:** signed + punish(min_contrib) стабилизирует вклады, общий рост
  против HP1. (а) кооперация через санкцию воспроизведена (дети из письма) ·
  (б) second-order free-rider победил — кто платит за наказание, тот и проиграл.
- **HP3 (ГЛАВНАЯ):** punish(max_body / coalition) → страта коалиции?
  (а) topGap > 1 / устойчивая страта → ПРИНУЖДЕНИЕ ПРОБИВАЕТ ПОТОЛОК, который
  не пробило согласие — первый властный механизм башни 🔖🔖 ·
  (б) NULL → даже захваченная санкция не строит страту — потолок тела
  фундаментален.
- **HP4:** захват снижает СРЕДНЕЕ благосостояние при ≈равном абсолюте коалиции
  (подростки: те же 45, группа беднее) — элита покупает относительную позицию
  ценой общего блага (смычка с G2 pie-strangling).

Гейты Фазы 1:
- **`MH3-OFF`** — pg_on=False, punish_on=False: ВСЕ якоря бит-в-бит.
- **`MH3-CONS`** — конструктив: pool-поток за раунд ≤ физически доступного
  soil; Σmass инвариант на каждом тике.
- **`MH3-PUNISH`** — не-no-op: мир с punish_on расходится (fingerprint);
  каждый штраф в логе имеет голосование-большинство на момент наведения.
- **`MH-mass` / `MH-replay` / `MH-ledger`** на всех новых путях; `verify_all`
  → ALL PASS.

Свип Фазы 1: m (3 точки из фазы 0) × visibility {anon, signed} ×
punish {off, min_contrib, max_body, coalition}; сиды 7/8/9; T=700.
Разреженно: не полная решётка, а осмысленные срезы (HP1: anon×off по m;
HP2/HP3/HP4: signed × стратегии при пороговом и надпороговом m).

**СТОП после свипа Фазы 1.** Решение Стана о Фазе 2 — по результатам

## Фаза 2 — энфорсер на долг (по слову Стана после стоп-точки)

- [ ] **2.1** `debt_enforce_on` (дефолт False): просроченное требование
      (стадия по K4-лестнице) исполняется принудительно — изъятие из body
      должника в пользу кредитора, с соблюдением K5-порога (изъятие не убивает:
      принудительный платёж тоже режется бюджетом до DEATH — принуждение
      забирает массу, не жизнь; остаток висит требованием).
- [ ] **2.2** Издержка энфорсмента: доля изъятого → в soil (принуждение не
      бесплатно; кто её несёт — кредитор из изъятого). Наведение — через тот же
      орган Фазы 1 (голосование/деме), НЕ автоматом: энфорсмент требует
      коллективной санкции.
- [ ] **2.3** Печать: исполненные требования, отказы органа, потоки
      кредитор/должник, Gini/topGap кредиторов.

Пре-регистрация Фазы 2:
- **HD1 (ГЛАВНАЯ):** долг + принуждение → страта кредиторов?
  (а) topGap > 1 → долг становится властью ТОЛЬКО с энфорсером — финальный
  трофей линии H: власть = требование × принуждение 🔖🔖 ·
  (б) NULL → даже сила не делает долг властью на консервативном субстрате —
  тело правит абсолютно, линия H закрыта дважды.
- **HD2:** investment-кредит оживёт? (а) гарантия возврата рождает
  инвестиционное кредитование (HHB2-загадка решена: дело было в риске) ·
  (б) investment = 0 и с энфорсером → дело в излишке/мотиве, не в риске —
  записать, вопрос уходит из линии H в экономику субстрата.

Гейты Фазы 2: `MH3-ENF-OFF` (бит-в-бит), `MH3-ENF-K5` (конструктив:
принудительное изъятие не пробивает DEATH-порог), не-no-op, mass/replay/ledger.
