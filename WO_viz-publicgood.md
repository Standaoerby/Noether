# WO — витрина «Общественное благо»: эксперимент с детьми, наглядно

Дата: 2026-07-13. Составлен Гайкой по запросу Стана: «максимально понятные
условия, таймлайн, наглядные результаты». Уровень A («экран преподавателя»)
с бесплатным довеском уровня B (степпер по турам).
Исполнитель: Claude Code. Ветка `feat/viz-publicgood` от `origin/main`.

> **Зачем.** H3 Фаза 1 воспроизвела полевой эксперимент из письма (public goods,
> две группы, два круга) — но результат живёт в свипах и агрегатах. Задача:
> одна самодостаточная HTML-страница, которую можно показать преподавателю,
> подростку или читателю книги — и за две минуты человек, не знающий Noether,
> понимает правила, проживает игру тур за туром и видит, кто выиграл и почему.
> Плюс PNG-выжимка для книги: полевые данные письма рядом с субстратными.

## Задача 2 — сценарный прогон (не свип)

- [ ] **2.1** Одна дема ~12 пешек (размер детской группы из письма), ОДИН seed,

      - **Круг 1** — anon, punish off (обе группы письма делали одно и то же);

- [ ] **2.3** Шкала денег: масса → «деньги», нормировка стартовым телом = 20.
      Косметика проекции, не мира. Один множитель, напечатан в сноске.

## Задача 3 — страница (viz/pg/index.html, самодостаточная, file://)

- [ ] **3.1 Понятные условия** — карточка правил ПЕРВЫМ экраном, языком
      преподавателя: «У каждого 20 денег. 5 туров. Каждый тур вы отдаёте
      сколько хотите в общий банк. Банк увеличивается и делится ПОРОВНУ на
      всех — даже на тех, кто отдал 0. Цель — остаться с наибольшей суммой».
      Для круга 2: «+ все ставки подписаны; после тура голосованием большинства
      один игрок штрафуется на 20%». Сворачиваемая сноска «как это устроено
      в башне» (масса/soil/синергия — физика, не магия; ссылка на WO H3).
- [ ] **3.2 Таймлайн** — центральный элемент: степпер «Тур 1 → 2 → 3 → 4 → 5»
      (клик/стрелки). На каждом туре, для каждой из трёх панелей:
      строка вкладов всех 12 участников (круг 1 — анонимные серые столбики;
      круг 2 — поимённые), событие штрафа (кого, сколько голосов, подпись
      логики: «наказали самого жадного» / «коалиция сожгла самого богатого»),
      текущий счёт каждого. Три панели идут синхронно — один степпер.
- [ ] **3.3 Наглядные результаты** — финальный экран:
      - кривые суммарного вклада по турам, три линии (затухание / удержание /
        захват) — та самая диаграмма, что преподаватель показывал на рефлексии;
      - итоговая таблица: максимальный выигрыш · средний · суммарный банк,
        по трём панелям;
      - «лента штрафов»: кто кого сжигал, по турам;
      - **сравнение с полем**: рядом числа письма (круг 1 макс ~60/45; дети
        круг 2 ~100; подростки ~45 при обедневшей группе) и числа пешек —
        подпись «люди на финской базе · пешки на консервативном субстрате».
- [ ] **3.4** Стиль — glass-семейство (тёмная тема, та же типографика), но
      БЕЗ зависимостей от glass-данных: страница полностью автономна,
      данные вшиты JSON-блоком.

## Приёмочный чек-лист наглядности (вместо формального гейта)

1. Правила видны без скролла и без единого субстратного термина.
2. Любой тур читается одной строкой: «кто сколько дал, кого наказали, почему».
3. Финал отвечает за 10 секунд: кто выиграл, какая группа богаче, что сделал
   захват. 4. Страница открывается двойным кликом (file://), без сервера.
5. Числа страницы == числам EventLog (спот-чек трёх значений в отчёте).
