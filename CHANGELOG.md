## 2026-06-26 — vectorize the shared per-cell pooling pass (`sim_pool`) — pure speed, bit-identical

Factored the O(co-located² × candidates) triple loop that `sim_warn` and `sim_evidence` each ran in `_social_exchange` into one shared, numpy-vectorized pass (`sim_pool.py`). **Behaviour-preserving optimization** — every protected fingerprint holds bit-for-bit; no rule, metric, or invariant changed. This is the one authorized reason to touch the locked reputation modules; the verdict is by **output-fingerprint reproduction**, not file byte-identity (their bytes change).

- **`sim_pool.py`** (new, **not** a tower module — not registered in `verify_all.py`): `_gather` takes one snapshot of `world.trust` per cell and builds the shared numpy matrices (member×member trust for credibility, member×candidate reports via `_gossip_report` so the smear/meta hook still applies, opinion mask, current trust); `min_count_update` applies the downward-only K-witness rule (`sim_warn` = K=1, `sim_evidence` = K) vectorized over sources — `min`/distinct-count are order-independent, so the result is exact. `A == S` is allowed, matching `sim_warn`'s neighbourhood semantics (the K=1 ≡ warn anchor depends on it). Snapshot-read / live-write and `sorted(...)` iteration are preserved (hash-independence).
- **`sim_warn.py`** / **`sim_evidence.py`**: `_social_exchange` is now a one-line call into `sim_pool` (K=1 and `self.k_witness` respectively). Logic identical; files re-verified bit-for-bit.
- **`sim_gossip.py`**: **unchanged (byte-identical to before)**. Its trust-weighted convex *average* is a sequential, order-dependent SUM; vectorizing it over receivers reproduces the exact bits (verified) but is *slower* than the scalar loop (each source needs its own numpy step rather than one reduction), so — per the WO's guidance — it keeps its scalar fold. The win comes from the two min/count modules.

  - heavy-trio sum **≈ 505 s → ≈ 232 s** (≈ 2.2×); since `verify_all` runs each module twice, this roughly halves the gate's dominant cost.

## 2026-06-26 — evidence-count gossip (K-witness): tuning the conviction↔slander knob (`sim_evidence`, module 17)

Gossip still only ever lowers (recovery is personal re-verification). K becomes a tunable dial on the accountability-vs-slander fork module 16 exposed. **No LLM, no endpoint, no RNG, no new dynamics** (touches only auxiliary `trust`; matter conserved). `sim_comm`/`sim_trust`/`sim_gossip`/`sim_warn` are **not edited** — `sim_evidence` is a parallel `TrustCommWorld` subclass.

## 2026-06-26 — warnings-dominate gossip: distrust pins the liar — and weaponizes slander (`sim_warn`, module 16)

Added module 16, `sim_warn`, replacing module-15's opinion-**averaging** gossip with a rule where **warnings dominate**: a receiver pulls its trust in S DOWN toward the lowest *credible* report it hears, and gossip never raises trust (only personal re-verification does). This is the fix module 15's diagnosis pointed at (the aggregation rule, not the act of sharing) — and it exposes the **accountability-vs-slander fork**. **No LLM, no endpoint, no RNG, no new dynamics** (touches only auxiliary `trust`; matter conserved). `sim_comm`/`sim_trust`/`sim_gossip` are **not edited** — `sim_warn` is a parallel subclass of `TrustCommWorld`.

- **`sim_warn.py`** (new): `WarnCommWorld(TrustCommWorld)` overrides `_social_exchange` with a **downward-only** update — for each co-located receiver B and speaker S, gather reports only from sources B still trusts (`>= TAU_SOURCE = 0.35`), take the worst, and set `trust[B][S] = min(current, worst)`. The min update is order-independent, so determinism is robust. Recovery happens only through re-verification, so **vouching is inert and the only gossip-borne attack is slander**. `_gossip_report` is honest by default; under `smear=True` the lying elite (speakers) fabricates a maximal warning (`0.0`) about any speaker it currently rates credible (`rep >= TAU_SOURCE`) — i.e. an honest-looking rival; liars already carry low reputation, so the bloc is shielded implicitly.
- **Experiment (seed 7, 300 d, OFF / LOCAL / WARN / WARN+SMEAR) on `{deceptive, mock-strategic}`** (AVG cited from module 15, not recomputed, to keep runtime lean):
  - **Q1 — pins the brazen liar (averaging could not):** YES. Trust in liars drops **below** the gate τ=0.35 — deceptive **0.391 (LOCAL) → 0.202 (WARN)**, mock 0.423 → 0.215 — vs averaging's *rise* to ~0.88. For the indiscriminate **deceptive** liar this shrinks the capture gap (+0.102 → +0.062, Δ−0.040) and pinning helps. For the **strategic** mixed liar, pinning improves the audience's belief (error 85.8 → 71.8) but the gap doesn't shrink (+0.035 → +0.097) — gating the speaker also cuts off its *occasional truthful* claims, so the audience loses information. Accountability is real but asymmetric in its ecological payoff.
  - **Q2 — weaponizes slander:** YES. With smear, honest-speaker reputation **tanks** (mock **0.289 → 0.101**) and the audience's belief degrades (error 71.8 → 79.8) — one fabricated warning propagates exactly as well as a true one. The slander does *not* cleanly restore the elite's capture gap (mock Δ−0.042; deceptive has no honest speakers to smear) — it is scorched-earth on honest reputation, not self-enrichment. Timing nuance: smearers are themselves caught lying about food, so their trust falls below `TAU_SOURCE` and their warnings stop being heeded — honest reputation lands at 0.101, not 0.0, partly recovering once the smearer loses credibility.
  - **Headline:** the accountability-vs-slander fork — *warnings-dominate pins the brazen liar that averaging could not, and the very same sensitivity lets the elite slander an honest rival with one fabricated warning.* Averaging exonerates the guilty; warnings-dominate risks convicting the innocent. 🔖 (Next: evidence-count / K-witness as the partial cure.)

Self-verifies — `matter_drift < 1e-9`; **replay-FROM-LOG bit-identical**; metric fingerprint **`419b5a4ee5adaff3`** with a recompute self-check; cross-process byte-identical. Gate **16/16** deterministic (sim_warn ~124 s/run; the gossip-style pass is O(co-located²) — the full gate is ~9.75 min, under the 600 s per-module timeout).

## 2026-06-26 — trust-weighting: does accountability break the lie equilibrium? (`sim_trust`, module 14)

Added module 14, `sim_trust`, making listeners **accountable**: each tracks a per-speaker reputation, verifies claims when it later visits the claimed cell, and stops acting on speakers it has caught lying — then measures whether that breaks the extraction equilibrium `sim_comm`/`sim_comm_llm` exposed. Trust is a property of the *listener*, orthogonal to who speaks, so it runs on the existing deterministic regimes — **no LLM, no endpoint, no RNG, no new dynamics** (it adds only auxiliary bookkeeping; matter still conserved).

- **`sim_comm.py`** (behaviour-preserving seam, output byte-identical): the inline `# naive trust about a remote cell` listener-absorption loop is factored into an overridable `_absorb_claim(self, L, B, claim, true_B, spk)` whose default body is the exact prior logic; the loop now calls it. Mirrors how the `_decide_claim` speaker seam was added. `sim_comm.py` canonical stdout fingerprint **`a91480561b6de937`** verified intact.
- **`sim_trust.py`** (new): `TrustCommWorld(CommWorld)` adds `self.trust[listener][speaker] ∈ [0,1]` (default **1.0** — full benefit of the doubt, so trust-ON starts identical to trust-OFF and diverges only as lies are caught) and `self.claimed_by[listener][cell] = (speaker, claimed)`. It overrides `_absorb_claim` (record what I was *told* unconditionally; act on it only if `trust ≥ TAU_TRUST`) and `_observe` (on arrival, verify the claim against real food and update reputation: kept promise `t ← 1−(1−t)·KEEP_RECOVER`, broken `t ← t·BREAK_DECAY`). Reputation is **heritable** (a newborn inherits copies of its parent's) and dropped on death. An optional `policy` routes the speaker seam like `LLMCommWorld`, so `MockStrategicPolicy` can drive the accountable audience. Constants are documented **definitions**: `TAU_TRUST=0.35`, `TOL_TRUST=0.05 kg`, `BREAK_DECAY=0.5`, `KEEP_RECOVER=0.5`.
- **Experiment (seed 7, 300 d, ON vs OFF per regime)** — capture gap `elite − audience mean body` (kg):
  - `mock-strategic`: **+0.087 → +0.035 (shrinks 60%)** — accountability substantially bites the *targeted* emergent liar;
  - `deceptive`: **+0.098 → +0.102 (~0)** — the scripted, indiscriminate liar with *moving* oases barely budges: victims can't pin a stable track record, so reputation never falls below the gate (trust-in-liars 0.391 > τ). A crude propagandist is paradoxically *more* robust to local accountability than a strategic one. 🔖
  - `honest`: capture stays ~0, but belief-error improves **4.39 → 2.82 kg** (recovery rewards consistent honesty).
  - Headline: accountability **shrinks the liar's capture but, being local and lagged, does not erase it** — the residual is the finding, exactly as anticipated.

Gate stays green (**14/14**, deterministic).

## 2026-06-26 — deception modes: separate "soft" puffery from "hard" diversion

Added a **deception-mode metric** to `sim_polariz` that splits the binary `truthful` flag into qualitatively different lies, so the finding *"deception evolves: substitution → diversion → inflation"* is quantitative, not anecdotal. **No new dynamics — measurement only**, like the rest of `sim_polariz`. Motivated by a live `qwen3:14b` cohort run where `lie fraction` read 1.000 even though most claims pointed at real cells with tiny inflations (real 7.82 → claim 8.0), a minority being genuine rival-diversion.

- **`sim_polariz.py`**: new `classify_claim(claim_food, true_food) -> (mode, e, r)` and `deception_modes(log) -> dict`, a pure, deterministic, log-only breakdown that **partitions** every `communication` claim into three classes (shares sum to 1.0, asserted): **truthful** (`|e| ≤ TOL_ABS`, `e = claim − true`), **soft/puffery** (positive small *relative* inflation of a real cell, `e > TOL_ABS` and `r ≤ R_SOFT`, `r = e/max(true,ε)`), **hard/diversion** (everything else — gross over-claim `r > R_SOFT`, or under-claim `e < −TOL_ABS`). `TOL_ABS = 0.05 kg` and `R_SOFT = 0.25` are documented **definitions**, not tuned knobs. The metric measures *realized error*, not intent (a stale-but-honest claim still lands by its magnitude). The relative-over-claim mean is taken only over lies against cells with real food (`true > TOL_ABS`); pure fabrication at an empty/decayed cell is a hard lie measured in kg, not a degenerate ratio.
- **Recomputed regimes (seed 7), printed as a new `DECEPTION MODES` block** — soft / hard / truthful shares: `none` (no claims); `honest` 0.016 / 0.222 / 0.762 (its "soft" bucket is memory *staleness*, mean ~1.1 kg, not malice); `deceptive` **0 / 0 / 1.000** (pure substitution, mean hard error **144.7 kg**); `mock-strategic` 0.003 / 0.049 / 0.948. Scripted-deceptive is overwhelmingly **hard**, exactly as expected; the big *puffery* bucket lives in the live cohort, not the scripted gate.
- **Fingerprint**: `sim_polariz`'s internal self-check fingerprint changed (expected — new deterministic output lines) from `ac7fcef400f48656` to **`6c4952f66da8326e`**; the recompute self-check still passes byte-identically, and `sim_polariz` runs cross-process byte-identical. This is the **only** allowed fingerprint change — the gate-level guarantees hold: `verify_all.py` **13/13** deterministic, `sim_comm.py` canonical stdout byte-identical, `sim_comm_llm.py` fingerprint **`f353ac30db73b770`** intact.

Its offline `--selftest` gains a hand-built three-claim log (one truthful, one soft 7.82→8.0, one hard diversion) asserting the expected 1/1/1 split — `deception_modes` works on any `EventLog`, including a JSONL-loaded cohort log; not required by `verify_all`.
