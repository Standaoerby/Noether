## Решения, зафиксированные до кода (из сессии 2026-07-03)

1. Мир детерминирован; недетерминизм (LLM) — только mod B, через лог. mod A полностью детерминирован.
2. Базовый мир полиса — **`AppropriationWorld`** (полис-с-экономикой: лидер может быть владельцем, директива влияет на кинетику оборота — микрокосм всей башни).
3. Личность = структурный вектор из ручек башни (не промпт). Демерзель = Pawn + directive.
4. Демерзель смертен; salience-канал для средств; **ученик/ритуал НЕ в mod A** (спроектированы в конституции, реализуются C/D).
5. Старт — **1–3 дома × 2 поколения**; размер эмерджентный из ресурса, лимита в коде нет.
6. Метрика **элитность = доля × живая база** (ловит «корону на кладбище») — обязательна с mod A.

## 1. `personality.py` — личность-вектор

Пять осей, каждая — переиспользование откалиброванной ручки башни:

```python
@dataclass(frozen=True)
class Personality:
    hunger_caution: float     # [0,1]  осторожность у DEATH-порога (stake s)
    deception_lean: float     # [0,1]  склонность искажать claim (cohort typology)
    attention_K: int          # 4..32  бюджет внимания (sphere K)
    trust_gate: float         # [0,1]  доверчивость к чужим claim (trust τ)
    stake_sensitivity: float  # [0,1]  насколько давление гнёт поведение (stake градиент)
```

- пресеты: `BASELINE` (нейтраль, все 0.5 / K=8), `CAUTIOUS`, `RECKLESS`, `DEMAGOGUE` (высокий deception_lean).
- **детерминированный посев личностей:** от `oid` через тот же RNG-паттерн, что башня (сортированный обход, seed-производный) — личность воспроизводима, не случайна между прогонами.
- личность — read-структура; влияет на восприятие/решение, не на массу.

## 2. `pawn.py` — толстая пешка

`Pawn` оборачивает `Animal` (не заменяет: `oid,i,j,gene,body,age` остаются каноном), добавляет:
- **арка-фазы** (read-модификатор над `age`, не новая масс-операция):
  ```
  INFANT   age < A_mat        (безрассуднее: hunger_caution снижен)
  MATURE   A_mat ≤ age < A_old (репродукция, полная личность)
  ELDER    A_old ≤ age         (осторожнее, attention_K падает — забывчивость)
  death    body<DEATH (канон) ИЛИ age ≥ A_max
  ```
  **Калибровка из данных (башня, сид 7, rho=0):** средняя жизнь ~120, медиана 119, размах→300.
  → `A_mat=20, A_old=100, A_max=300` (обычная пешка); фазы плясать от базовой ~120, НЕ от обвального
  режима присвоения (там median 7 — насос оборота, не естественная жизнь).
- **память/belief** — доступ к башенному belief через существующий интерфейс (sphere/comm), Pawn лишь
  индексирует «что эта пешка знает» для арки (старший знает больше).
- инвариант: фазы — чтение возраста, дрейф <1e-9 держится.

## 3. `directive.py` — слой интента бога

```python
@dataclass
class Directive:
    goal: str            # "PROMOTE" | "SOW_DISCORD" | "IMPLANT" | "GROOM_SUCCESSOR"(задел, no-op в A)
    target: int | None
    payload: dict
    constraints: dict    # {"covert": True, "max_exposure": 0.3}
    issued_t: int
```

**Средства — через salience-канал (мод-21, готов):** Демерзель добавляет significance в бюджеты внимания
через существующий `injected`-ledger. Детерминированный `choose_means(personality, perception, directive)`:
- `PROMOTE(target)` — поднять significance target-клеток/claim'ов в бюджетах соседей (двигать к вниманию→владению).
- `SOW_DISCORD` — инъекция противоречивых claim'ов + подрыв trust (готовый gossip/warn-канал клеветы).
- `IMPLANT(belief_vec)` — повторять belief в communication, пока не приживётся/отвергнется.
- `GROOM_SUCCESSOR` — **задел, no-op в mod A** (директива принимается, средство пустое; механика в C/D).

Атрибуция: каждый ход Демерзеля логируется тройкой `directive → means → world_delta` (event-log).

## 4. `polis.py` — единица мира

```python
@dataclass
class PolisConfig:
    seed: int = 7
    resource_profile: dict = ...   # avail, N_OASIS → ёмкость эмерджентна (НЕ лимит числа)
    arena_side: int | None = 6     # box6 (AppropriationWorld толще)
    appropriation: float = 0.5     # rho — полис имеет экономику
    owner_policy: str = "claim"    # эмергентная территория
    founding_houses: int = 3       # 1-3 дома старт
    generations: int = 2           # 2 поколения посева
    t_awaken: int = 9999           # ∞ по умолчанию → чистый аквариум ≡ канон
    demerzel_personality: Personality = DEMAGOGUE
    demerzel_directive: Directive | None = None
    demerzel_A_max: int = None     # None → порядок цивилизационной арки (см. ниже)
```

- `Polis(AppropriationWorld)` — наследует субстрат; **семейный посев**: 1-3 дома × 2 поколения через
  `_house` birth-механизм мод-25 (основатели + потомство), число пешек = следствие выживаемости при ресурсе.
- **t_awaken-шов:** до `t_awaken` полис == чистый `AppropriationWorld` прогон. В `t_awaken` живой пешке
  (или новорождённой) присваивается `directive` — она становится Демерзелем. `t_awaken=∞` ≡ канон.
- **Демерзель-долгожитель:** `A_max` = порядка длины цивилизационной арки полиса (застаёт очаг целиком).
  Оценка арки = ~длина жизни линии `_house` до угасания; в mod A проще — `demerzel_A_max = 20 × A_max`
  обычной пешки как первый прокси (≈6000 тиков; на практике полис короче — Демерзель почти всегда
  переживает очаг, что и нужно). Точную привязку к длине `_house`-линии — калибровать в приёмке.

## 5. `metrics.py` — атрибуция, элитность, живое окно

- **элитность (двойная):** `elite_share` (owner_bio_share, относит.) И `elite_absolute` (доля × живая
  биомасса × alive) — «корона на кладбище» видна как высокий share при низком absolute.
- **живое окно директивы:** [issued_t, death_t Демерзеля]; все директива-метрики считаются на окне,
  не размазываются нулями после смерти.
- **атрибуция-тройка:** для каждого хода Демерзеля — (directive, means, world_delta) в лог.
- **дельта бога (для mod C, но метрика закладывается тут):** исход полиса директива-ON vs OFF на окне.

## 6. `run_polis.py` — прогон + гейты + demo

Гейты (стиль пробников/legitimacy — B0 цитировать дословно, не реконструировать):
1. **B0 канон:** `t_awaken=∞, directive=None, приводя PolisConfig к башенным дефолтам`
   (rho=0, founders, open, salience off) → `world.state_fingerprint() == CANON_COMM` (`a91480561b6de937`).
2. **B1 приводимость к живому присвоению:** `t_awaken=∞` при headline-конфиге полиса (rho=0.5, claim,
   box6) → `== appropriation_fingerprint` соответствующего прямого прогона (полис = чистая обёртка).
3. **read-only-safe:** fp мира до метрик == после (Pawn/metrics ничего не мутируют).
4. **матерь:** `matter_drift() < 1e-9` на каждой конфигурации (арка-фазы масс-нейтральны).
5. **self-check:** polis-fp (sha256 отформатированной трассы директива→средства→дельта, `.9f`)
   дважды бит-в-бит.
