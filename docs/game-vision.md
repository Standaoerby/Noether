# Noether Game — видение (рабочее имя: «Демерзель»)

Дата: 2026-07-13. Из квиза Стана (16 ответов) + отчёта исследования.
Это НЕ приказ — это компас. Приказы нарезаются по этапам.

## Одним абзацем

Хардкорная десктопная 2D-игра класса «супер-RimWorld» поверх научной
симуляции Noether. Игрок — Демерзель, бог-советник: не командует, а влияет
нашёптываниями через легальные каналы пешек. Партия начинается выбором
точки высадки на процедурно сгенерированном мире; общество живёт по честной
физике башни (сохранение массы, долг, репутация, коалиции, институты
наказания); климат медленно дрейфует и гонит кризисы и миграции
(гумилёвщина приветствуется). Цель — провести общество до способности
покинуть планету. Сессия 30–40 часов, теоретически бесконечная.
Аудитория: Стан и пятеро друзей. Побочный продукт — социологические данные:
как ведёт себя человек-бог (реплеи сессий = материал исследования).

## Столпы (по отчёту, проверены индустрией)

1. **История живёт в логе.** EventLog — нарративный движок (урок DF/RimWorld).
   Хроники, карточки пешек, лента штрафов — проекции, не выдумки.
2. **Полу-контроль.** Пешки автономны; Демерзель влияет, но не управляет.
   Нашёптывание = инъекция в поток памяти агента (модель Stanford Generative
   Agents: «внутренний голос»). Кнопки-директивы = структурированные интенты;
   свободный текст = LLM-перевод в интент, ядро решает легальность.
3. **Форсинг имеет цену.** Жёсткая перезапись интента копит стресс/
   подозрительность → психоз пешки (RimWorld mental break / CK3 stress) и
   событие, видимое сообществу → ярлык «ведьмы» → санкции института
   наказания (наш H3-орган — уже в каноне!). Теоретическая база:
   реактивность Брема. Принуждение не бесплатно — это и наука, и драма.
4. **Наблюдаемость важнее симуляции.** Урок Sylvester: игроки не видят
   глубину без UI. Инвестиции в инспекторы/оверлеи/хроники ≥ инвестиций
   в механики.
5. **Storyteller дозирует, физика решает.** Климат и кризисы подаются
   слоем-драматургом поверх EventLog (кривая напряжения а-ля Cassandra),
   но исходы считает честное ядро. Драматург выбирает КОГДА, никогда — ЧТО.

## Рамки честности (конституционный уровень)

- Канон неприкосновенен; сохранение массы святое; команды игрока — события
  в логе, реплей полный (seed + командный лог = бит-в-бит).
- Недетерминизм разрешён ТОЛЬКО косметике клиента, пересев на границах фаз.
- LLM никогда не принимает механических решений — только переводит текст
  игрока в интент-кандидаты (защита от «уболтать агента» промпт-инъекцией).

## Этапы (каждому — свой WO)

0. **Каркас** (`WO_game-stage0.md`): сервер+клиент, агенты на экране,
   пауза/скорости. ← ЗАРЯЖЕН, старт завтра.
1. **Наблюдаемость**: инспектор needs/thoughts, оверлеи (богатство/долг/
   репутация), хроники-Legends из EventLog, интерполяция-полировка.
2. **Демерзель**: кнопки-директивы; свободнотекстовые нашёптывания через
   асинхронный LLM (локальный Ollama или дешёвый API, constrained JSON);
   форсинг → стресс → психоз/«ведьма» (потребует научного мини-витка в
   башне: механика стресса — с пре-регом, как всё у нас).
3. **Мир**: worldgen с точкой высадки (Перлин/симплекс, климат-поля по
   DF-конвейеру, в ядре), климат-дрейф, Storyteller-слой, запись сессий
   как научных данных.
4+. Цель «покинуть планету», династии, кризисные арки — по результатам
   жизни этапов 0–3.

## Развилки, оставленные Стану

- Имя игры (рабочее «Демерзель»).
- LLM для нашёптываний: локальный (Ollama) vs API — решить на Этапе 2
  по факту латентности/качества перевода текста в интенты.
- Механика стресса пешки: отдельный научный модуль башни (виток с пре-регом)
  или игровой слой поверх? Гайкина лапа за научный модуль — «ведьма» слишком
  близка к H3, чтобы отдавать её косметике.
