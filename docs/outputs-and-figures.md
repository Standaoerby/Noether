# Артефакты и фигуры

Лежат в `Noether/Artifacts/`. Все **регенерируются** запуском соответствующего модуля — это сгенерированные выходы, не исходник.

## `world_events.jsonl` (~2.4 МБ, 18510 событий)
Полная индивидуальная история компактного сохраняющегося мира из `sim_eventlog`. Универсальная схема:
```
Event(t, kind, scale, where, actor, parent, dm, data)
```
- `t` — день; `kind` — открытый словарь (birth/death/move/boom/crash/local_extinction/recolonize/sync_crash/cline_shift/cognition…); `scale` — individual/deme/world; `where` — (row,col) или None; `actor`/`parent` — id (parent делает родословные); `dm` — перемещённое вещество (кг, знаковое) для сверки с субстратом; `data` — произвольная нагрузка.
- Доказано **верным**: `reconstruct_live()` пересобирает живую популяцию из лога в одиночку и совпадает с симом на всех чекпойнтах. Родословная пешки #1907 — 13 поколений (основатель #2, ген 20.6°C → #1907, ген 22.0°C).
- Регенерация: `python3 Code/sim_eventlog.py`

## `pareto_front.png` (2 панели)
Из `sim_pareto`. Панель A: (H, C) на гиперболе H·C=1, цвет по температуре + помаркерные средние по рядам (холод/крупный → жара/мелкий = клин обходит фронт). Панель B: (плодовитость, жизнеспособность) — серое доминированное облако скрэмбл-temp_opt против эволюционировавших на фронте.
- Регенерация: `python3 Code/sim_pareto.py`

## `portfolio_effect.png` (3 панели)
Из `sim_portfolio`. Независимые временные ряды / синхронизированные / проверка sqrt-закона `CV_total = c·√((1+(n−1)ρ)/n)`.
- Регенерация: `python3 Code/sim_portfolio.py`
