# Инварианты сохранения

Что именно проверяет каждый слой и какие **наблюдаемые** дрейфы получены (не «должно быть ~0», а измеренные числа). Все величины в СИ; деньги слоёв — кг вещества, Дж энергии, Дж/К энтропии.

## Четыре инварианта
- **Масса** — `soil + plant + Σ body` постоянна (закрытая петля почва→растение→тело→почва). Переселение особи между клетками массу **не трогает** (тело едет с особью).
- **Энергия через границу** — модифицированный закон `E(t) − E0 == (вошло) − (вышло)`: Солнце внутрь по инсоляции, холод космоса наружу по Стефану-Больцману. Внутри замкнутого ящика — просто `E(t) == E0`.
- **Тело-в-почве** — то, что особь тратит на upkeep/умирание, возвращается в почву ровно (никакой утечки на индивидуальном балансе).
- **Энтропия** — монотонно растёт; извлечение работы пропущено через карно-гейт (нельзя извлечь больше термодинамически дозволенного).

## Зачем «относительный» аудит в `sim_space`
В горячем пути с numpy-диффузией абсолютная энергия накапливает арифметический шум; честнее аудит по кумулятивному нетто-потоку (`cum_net`), где `E_rel ~1e-14` показывает, что закон держится на уровне машинной точности, а не маскируется масштабом.

## Принцип над всеми
Сохранение — несущая идея ([Нётер](../README.md)): любой эмерджентный феномен выше (клин, рефугиум, Бергман, фронт Парето, портфельный буфер, эволюция веры) обязан расти на субстрате, который **ничего не подделывает**. Если инвариант падает — феномен выше недостоверен.
