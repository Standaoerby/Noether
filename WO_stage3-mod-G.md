## Фаза 2 — G2, заход 1: `EXTORT` (черновой порядок — дешевле, утвердить в 1.6)

**Механика:** перенос owner→extortionist — тот же сохраняющий тело→тело, что дань 23,
обратный знак. Гейт нелегитимности: работает ТОЛЬКО когда энфорсер (страж 24) НЕ
со-локализован — преступность живёт в тени присутствия.

**Пре-рег:**
- строит ли страту нелегитимный захват? да → легитимность вторична для физики;
  NULL → присвоение-23 безразлично к основанию права (острый тезис);
- ловит ли страж нелегитимный захват эффективнее легитимного вызова (baseline
  институт давил 966→122)? разница = измеримая цена нелегитимности;
- смычка с репутацией: метка вымогателя → снижение будущего доступа → самоограничение.

**Инфраструктура:** строка в реестре вербов (реестр расширяем by design); память
исходов получает ЛОКУСЫ (кто/где отказал) — структура счётчиков должна это стерпеть;
типизированный протокол live расширяется новым действием (паттерн C-LIVE).
Зеркальность к ВСТАВКЕ-29: меряем обе стороны «источника права» на одной механике.

## Фаза 3 — G2, заход 2: `DELEGATE` / `REVOKE` (главный трофей — михельсова дыра)

**Механика (всё на готовой инфраструктуре дани 23):** дань C→B (тело→тело); мета-дань
B→A, доля `m` от собранного (тело→тело); «право делегирования» — леджер-отношение,
permission-only, mass-neutral (kind-суффикс). Корень A физически отсутствует на клетке
делегата — в этом весь смысл: k делегатов = k клеток разом.

**Свип зуба отзыва (ОБЯЗАТЕЛЕН — REVOKE без зуба бессилен):**

| зуб | механизм | пре-рег предикт |
|---|---|---|
| (a) нет | B может игнорить (defect-флаг) | delegate ≡ распределённое владение; дельта РАВНА мод-23 |
| (b) репутация | дефектный делегат метится, теряет будущий доступ | мягко, вряд ли пробьёт потолок |
| (c) энфорсер | отзыв исполняет страж-24 | «черепахи вниз»: потолок переезжает на уровень стража |
| (d) авто | леджер сам откатывает (god-physics) | ⛔ ЧИТ — только контрольная граница честности, НЕ рабочий режим |

**Метрика (owner_gap слеп by design — новая ось):** доля потока через держателя
права-отзыва vs его собственное ТЕЛО; ключевой профиль — телесно-бедный +
потоко-богатый корень (власть кинетическая, смыкание с законом оборота);
глубина/ширина цепи. Урок mod F: **кого кладёшь в знаменатель — решает результат**
(реальный класс `owner_ids()`, не узкий `_owner_ids`).

**Контрольный дизайн:** DELEGATE при ВЫКЛЮЧЕННОМ наследовании; concentration-дельту
сравнивать с уже-измеренной дельтой `_house` (25). Чистый контраст: институциональный
vs биологический обход потолка присутствия (бюрократия vs династия).

**Фальсифицируемые исходы:** (a) даёт ровно профиль присвоения → зуб необходим,
аппарат без энфорсмента пуст; пробивает только при (d) → без субстратного чита
фазового перехода нет, башня подтверждена на оси контроля; пробивает при (b)/(c) →
найдена вторая проводимость власти. Все исходы информативны.

## Дисциплина и грабли (нарушать нельзя)

- PowerShell: `;` не `&&`; запуск `py`; хэши `Get-FileHash -Algorithm SHA256`.
- Байтовый перенос файлов + SHA-сверка с эталоном ДО прогона; версия хэшем, не глазами.
- Якоря святы: изменение blob — только условным суффиксом; OFF-термы байт-в-байт.
- Честные базы с ПЕРВОГО прогона (грабли HGG2/HG3: живой срез = селекция состава).
- Сравниваемые множества — на одной временной базе.
- Рефакторинг гейтов в предикаты → сразу гнать MG-OFF (ловит любой сдвиг).
- `tee` без `head` в пайпе (SIGPIPE); тяжёлые прогоны порциями с инкрементальным логом;
  фоновые процессы между вызовами не живут.
- Демография — ИСХОД, не фон: Gini/метрики при разных pop читать с оглядкой на состав.
- deny-лог: (а) галлюцинация ≠ (б) гонка ≠ (в) self_preempt — различать в данных.
