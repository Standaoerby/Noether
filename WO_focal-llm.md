Это самодостаточный work-order. Работай прямо в репо, гоняй тесты, в конце открой PR.

## Контекст
Башня из 11 модулей + только что добавленный `Code/sim_comm_llm.py` (фокальные LLM-говорящие
поверх `sim_comm`). В `sim_comm.py` уже есть шов `_decide_claim` и поле `"claim_exact"` в
`communication`-событии.

**Инвариант, который нельзя нарушить:** динамику `sim_comm.py` не трогай — его канонический
вывод обязан остаться **байт-в-байт**. Контрольные числа (seed 7): аудитория 2332 / 2000 / 1080;
биомасса 799.4 / 570.1 / 267.2; ошибка веры 0.00 / 4.39 / 142.7; элита 544 / 577 / 830.
Зависимости — только stdlib + numpy на верхнем уровне модулей; `anthropic` подключается
**внутри** `ClaudePolicy`/раннера, не на импорте.

## Задача 1 — вписать `sim_comm_llm` в гейт
В `Code/verify_all.py` добавь 12-й модуль:
```python
("sim_comm_llm", "focal LLM speakers: pluggable policy; deception as equilibrium"),
```
`sim_comm_llm.py` уже само-ассертит: сохранение во всех режимах, реплей повтором,
**реплей-из-лога**, и инертность `ClaudePolicy`; детерминирован на `MockStrategicPolicy`
(в `main()` API не дёргается). Прогон `python3 Code/verify_all.py` → ожидаем **12/12**,
`deterministic=yes` у всех. Если на верхнем уровне `sim_comm_llm.py` есть лишний импорт
сверх stdlib+numpy — убери (гард `anthropic` внутри метода/раннера).

## Задача 2 — домашний раннер живого Claude
Создай `Code/run_focal_claude.py` — CLI на `argparse`:
- флаги: `--focal` (oid через запятую), `--days`, `--think-every`, `--seed`, `--model` (default `claude-sonnet-4-6`);
- `from anthropic import Anthropic` — **импорт гардить внутри `main()`**, не на верхнем уровне;
- вызвать `run_policy(ClaudePolicy(client=Anthropic(), model=...), seed=..., focal=set(...))` из `sim_comm_llm`;
- сохранить event-лог в JSONL рядом со скриптом (формат как у `sim_eventlog`), чтобы `ReplayPolicy` потом воспроизвёл прогон бит-в-бит;
- напечатать таблицу аудитория-vs-элита, долю лжи (`truthful=False`) и сводку «заявленный `rationale` vs исход».
- Этот файл **не** добавлять в `verify_all` (требует API).
- Если `THINK_EVERY`/`DAYS` в `sim_comm` — модульные константы, дай раннеру переопределять их локально, не правя `sim_comm.py`.

## Задача 3 (опционально, строго за флагом — default не менять)
В `MockStrategicPolicy` добавь параметр `keep_threshold=0.5`: вынеси множитель из условия
`worth_keeping` (`here_food >= keep_threshold * best`). Default `0.5` сохраняет текущее
поведение (детерминизм гейта цел). Это позволит получить **смесь** «честен, когда нечего
защищать» вместо нынешних 100% лжи — спектр, а не бинарь.
