## Фаза 1 (виток H1) — механика

### 1.1 Заём (mass-neutral по построению)

- `store` кредитора → **тело** должника (голодный ест сейчас).
- Леджер: `debt[(creditor, debtor)] += amount * k` — обязательство, не масса.
- **Тождество для гейта:** `непогашенный ≡ Σ(выдано·k) − Σвозвращено`.

### 1.2 Ставка — эндогенная, фиксируется в момент договора

```
k_t = k_min + (k_max − k_min) · sat(D_t / S_t),   sat(x) = x / (1 + x)
D_t = совокупный непогашенный долг (спрос)
S_t = совокупный свободный store   (предложение)
```
`k` **фиксируется при выдаче** (винтаж договора), дальше не меняется; новые займы
получают новую ставку. Это даёт обратную связь: много долга → дорогой кредит →
больше дефолтов → больше кабалы.

**Подписать в коде как допущение (по образцу `m=0.7`):** `k_t` — свойство СИСТЕМЫ,
а не знание пешки. Голодный не торгуется, он принимает условие.

### 1.3 Платёж

Доля `r` дохода должника → `store` кредитора, каждый тик, пока долг не погашен.
Всё тело→store, масса сохраняется.

### 1.4 Три выхода из долга

1. **Погасить** — доход позволил;
2. **Дефолт** (отказ от долга) — детерминированный триггер: если `r·доход >
   метаболизм` (платить = умереть), пешка выбирает жизнь ценой прав → **кабала**;
3. **Смерть** — остаток переходит наследникам по `_house`; нет наследников —
   кредитор теряет (долг сгорает).

### 1.5 Лестница поражения в правах (ступени 0–3; ступень 4 — виток H3)

| ступень | статус | что отнято |
|---|---|---|
| 0 | свободный | ничего |
| 1 | **должник** | ничего; платит `r` дохода |
| 2 | **просрочивший** | нет новых займов; **claim заморожен** |
| 3 | **кабальный** (банкрот) | весь доход сверх метаболизма → кредитору; нет claim; **не speaker** (нет голоса); **его показания не считаются** (метка от кабального не клеймит вымогателя) |

**КРИТИЧНО (урок Фазы 4, вписан в канон дисциплины):** политика `reflex` НЕ
консультирует афордансы. Поражение в правах обязано гейтиться **НА ИСПОЛНЕНИИ**,
а не только на афордансе — иначе получим тихий no-op. Гейт `MH-BANKRUPT` это ловит.

## Гейты (все обязательны)

- **`MH-OFF`** — `debt_on=False`: все восемь якорей + GC-identity бит-в-бит.
- **`MH-mass`** — сохранение массы на всех путях (заём, платёж, дефолт, наследование).
- **`MH-replay`** — реплей из лога бит-в-бит.
- **`MH-ledger`** — тождество §1.1 держится каждый тик (допуск печати float).
- **`MH-BANKRUPT`** (не-no-op): мир с кабалой **отличается** от мира без неё
  (fingerprint расходится) И кабальный действительно лишён прав на ИСПОЛНЕНИИ:
  ноль claim'ов от кабальных, ноль засчитанных показаний, ноль займов.
  **Различение «no-op vs NULL» обязательно перед любым NULL-вердиктом.**
- `verify_all` → ALL MODULES PASS.
