## Что тут по-другому (ядро наряда — прочитать до кода)

Property-миры (23–27) меряли **владение** (owner_ids, cell_owner, appropriated_total) — их
`SnapFrame` уже несёт. Пробник ВСТАВКА-29 меряет **подавление вызова легитимацией** —
совсем другие величины, которых в снимке НЕТ:

- `_selfcensored` (int) — сколько вызовов владения **не поднято** из-за мифа (работа формулы).
- `_legit_events` (int) — сколько инъекций легитимности доставлено.
- `_legit` (dict `oid -> {cell: вес}`) — леджер накопленной легитимности на клетках.
- `succeeded` — успешные перевороты владения (E3-ось: challenge-flips).
- `legit_threshold` — порог самоцензуры (хедлайн 0.5; свип {0,.25,.5,.75,1}).

Находка, которую визуал должен показать (H1✓/H2 NULL): формула **душит вызов** (перевороты
box6 5634→0 при низком пороге) **без обвала ёмкости** (~98 живых против ~7 под налогом
мод-24) — но **страту не строит** (owner_gap на душу разбавлен НИЖЕ базы). «Формула покупает
молчание, не страту». Контраст всей находки — против института мод-24: тот давит вызов
ЦЕНОЙ базы (кладбище), формула — БЕЗ цены базы.

Значит визуал пробника — **не** про золотой класс владельцев, а про **тишину**: где вызов
задавлен мифом (self-censored клетки), при живой популяции. Это другой рендер.

## Задача 1 — доп-поля пробника в `SnapFrame` (`schema.py`)

Добавить (заполняются ТОЛЬКО для пробника; для property-миров остаются пустыми/нулём):
```python
selfcensored: int = 0        # накопленных подавленных вызовов на момент кадра
legit_events: int = 0        # накопленных инъекций легитимности
legit_cells: list = None     # [[i, j, weight], ...] клетки с накопленной легитимностью (из _legit)
succeeded: int = 0           # накопленных успешных переворотов владения (E3)
```
- `legit_cells` собирается из `w._legit`: агрегировать по клетке (суммировать веса всех oid на
  клетке) → список `[i, j, total_weight]`. Это «карта мифа» — где легитимность давит.
- Дефолты (`0`/`None`) держат обратную совместимость: property-снимки PR #30 не ломаются,
  `frames_from_jsonl` читает старые файлы (отсутствующие поля → дефолт; проверить, что
  dataclass с дефолтами это переваривает, иначе прочитать через `.get`).
- **fp-нейтральность:** поля живут в снимке, не в мире; `state_fingerprint`/`*_fingerprint`
  их не читают → snapshot-safe остаётся зелёным. Гейт докажет.

`frame_from_world(w, t, prev)`: если у мира есть атрибуты `_selfcensored`/`_legit` (пробник) —
заполнить новые поля; иначе оставить дефолты. `getattr(w, "_selfcensored", 0)` — не падать на
property-мирах.

## Задача 2 — регистрация пробника в `WORLDS` (`capture.py`)

Импорт:
```python

```
(если fingerprint-функция называется иначе — свериться: в коде self-check печатает через

Запись (сигнатура `run_probe` — из форензики, дословно):
```python
"legitimacy": {
    "run": run_probe,
    "fp": probe_fingerprint,   # ← подтвердить точное имя в коде
    "B0": dict(formula=False, sigma=0.0, enforce=False, appropriation=0.0,
               owner_policy="founders", arena_side=None,
               injection_strength=0.0, injectors=0),   # + sphere/salience-off оверрайды как у батареи PR#30
    "B0_anchor": CANON_COMM,                            # a91480561b6de937
    "B0_guard": lambda w: (w._selfcensored == 0 and not w._legit),
    "headline": dict(formula=True, legit_threshold=0.5, sigma=0.0, enforce=False,
                     appropriation=0.5, owner_policy="claim", arena_side=6),
    "baseline": dict(formula=False, sigma=0.0, enforce=False,
                     appropriation=0.5, owner_policy="claim", arena_side=6),  # формула OFF

```
**Критично свериться перед прогоном** (открыть `sim_legitimacy_probe.py`):
- точное имя fingerprint-функции (`probe_fingerprint`? иное?);
- полный набор B0-оверрайдов, сводящих пробник к канону `a91480561b6de937` — тройной guard
  `c0==CANON_COMM and _selfcensored==0 and not _legit` (из кода, строка B0-anchor); скопировать
  канон-конфиг из его же `__main__` self-check ДОСЛОВНО (как в PR #30 — неполный B0 уронит гейт);
- что `run_probe` принимает `days=0` (для pristine-build в `capture`).

## Задача 4 — agenda-слой на фронте (`static/`)

Пробник добавляется в селектор мира (`#world`) как «легитимация (agenda · ВСТАВКА-29)». Но
рендер — **другой слой**, не золотой класс:

- **Слой «тишина» (self-censored):** `legit_cells` рисовать как приглушённое наложение (напр.
  сине-серая полупрозрачная заливка, интенсивность ∝ весу легитимности) — «карта мифа»,
  где вызов задавлен. Тумблер `ly-legit` («легитимность»).
- **Плашка пробника** (вместо owner-контраста): три числа headline vs baseline —
  ```
  подавлено вызовов   selfcensored:  0  →  N        (миф работает)
  живых               alive:        ~7 (налог) → ~98 (формула)   ← без цены базы
  доля у владельцев   owner_share:  база → ниже     (страту НЕ строит)
  ```
  Двухрегистровые подписи (человеческое крупно / термин мелко), как везде.
- **Порог-свип** (переиспользовать `#sweep` из PR #31, но ось X = `legit_threshold` 0→1):
  кривая selfcensored (сколько мифа = сколько молчания) + alive (плоско-высокая, база цела).
  Это визуальная форма H1: «дёшево, но дозозависимо».
- Таймлайн-спарки из #29 переиспользуются (alive/owner_share); добавить `selfcensored(t)`.

## Задача 5 — подпись-рамка (честность находки)
